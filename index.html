Example 7 : The functions binom.test and prop.test



Suppose that we have a binomial experiment with \(n=20\) trials. The observed number of successes is y=4. The sample proportion is y/n=0.2, which is the mle for the probability of success. Suppose that we would like test that \(H_0:\pi=1/3\) against \(H_a:~\pi\neq 1/3\).

Score Test:

To get the score test, and also the 95% Wilson CI (also called the score CI), we can use the prop.test function. The \(p\)-value for testing \(H_0:\pi=1/3\) against \(H_a:~\pi\neq 1/3\) with the score test is 0.2059. At \(\alpha=5%\), the evidence against \(H_0\) is not significant. We cannot conclude that \(\pi \neq 1/3\). 

> prop.test(x=4,n=20,p=1/3,correct=FALSE)

        1-sample proportions test without continuity correction

data:  4 out of 20, null probability 1/3
X-squared = 1.6, df = 1, p-value = 0.2059
alternative hypothesis: true p is not equal to 0.3333333
95 percent confidence interval:
 0.08065766 0.41601743
sample estimates:
  p
0.2


Comments:
  • By default, the null hypothesis is \(H_0:~\pi=0.5\). So if we did not provide \(p=1/3\), then we would be testing that \(p=0.5\).
  • By putting the prop.test object into the names function, we obtain the names of the component of the object. 

    > names(prop.test(x=4,n=20,p=1/3,correct=FALSE))
[1] "statistic"   "parameter"   "p.value"     "estimate"    "null.value"  "conf.int"    "alternative" "method"      "data.name"


    The 6th component is the confidence interval, so to obtain just the interval we can ask for the 6th component, or simply refer to it by name. In this case, the 95% Wilson confidence interval for the population proportion is \((0.081; 0.416)\). 
    > prop.test(x=4,n=20,p=1/3,correct=FALSE)$conf.int
[1] 0.08065766 0.41601743
attr(,"conf.level")
[1] 0.95
> prop.test(x=4,n=20,p=1/3,correct=FALSE)[6]
$conf.int
[1] 0.08065766 0.41601743
attr(,"conf.level")
[1] 0.95


  • The default confidence level is 95%, but we can change with the 
    conf.level
    argument. Here is the 98% Wilson CI for \(\pi\). 
    > prop.test(x=4,n=20,p=1/3,correct=FALSE,conf.level=.98)$conf.int
[1] 0.06855279 0.45922739
attr(,"conf.level")
[1] 0.98
  • The Wilson CI at the level \(1-\alpha\) is the inversion of the score test, that is \[ \mbox{Wilson CI}=\{\pi_0 \in [0,1]~:~ p\mbox{-value}(\pi_0)>\alpha\}, \] where the \(p\)-value(\(\pi_0\)) is computed from the score test for testing \(H_0:\pi=\pi_0\) against \(H_a:\pi\neq \pi_0\).


Exact Binomial Test: If we use the function binom.test, we will get the exact binomial test, and the 95% Clopper-Pearson CI for \(\pi\). The \(p\)-value for testing \(H_0:\pi=1/3\) against \(H_a:~\pi\neq 1/3\) with the exact Binomial test is 0.2434. At \(\alpha=5%\), the evidence against \(H_0\) is not significant. We cannot conclude that \(\pi \neq 1/3\). 
> binom.test(x=4,n=20,p=1/3)

        Exact binomial test

data:  4 and 20
number of successes = 4, number of trials = 20, p-value = 0.2434
alternative hypothesis: true probability of success is not equal to 0.3333333
95 percent confidence interval:
 0.057334 0.436614
sample estimates:
probability of success
                   0.2


Comments:
  • It is the minimum likelihood method that is used to compute the \(p\)-value. Let \(w=4\) be the observed value of successes, we say that a number \(x\) in \(\{x:0,1,\ldots,n\}\) is as extreme (according to the minimum likelihood method) if \(p_{\pi_0}(x)\leq p_{\pi_0}(w)\). We compute the \(p\)-value by adding up all probabilities associated to the extreme values. Here is a plot of the pmf for a \(B(n=20,\pi=1/3)\) distribution. We see that values \(0,1,2,4,10,11,\ldots 20\) as as extreme as \(y=4\) for this distribution. So we compute the \(p\)-value is follows: \[ P(W\leq 4|\pi=1/3)+P(W\geq 10|\pi=1/3)=0.2434. \] 



    pmf<-dbinom(0:20, 20, 1/3)
pmf.df<-data.frame(w=0:20,pmf)
x11(width = 6, height = 6, pointsize = 12) ## to get a new graphics window (not necessary with R Studio)
plot(x = pmf.df$w, y = pmf.df$pmf, type = "h", xlab = "Number of successes", ylab = "Probability",
     main =expression(paste("Binomial Distribution: ",italic(n) == 20, " and ", italic(pi) == 1/3)),
     panel.first = grid(col="gray", lty="dotted"), lwd = 3)
abline(h = 0)
abline(h=dbinom(4,20,1/3))
    Here is the computation of the \(p\)-value: 
    > sum(dbinom(c(0:4,10:20),size=20,prob=1/3))
[1] 0.2434066
  • Alternatively, we could use the central method (also called the two-tailed method) to compute the \(p\)-value for the exact Binomial test. We put a critical region (i.e. rejection region) of size \(\alpha/2\) in both tails. This means, that we reject \(H_0\) if \[ P(Y\leq y|\pi_0)\leq \alpha/2 ~~~ \mbox{ or } ~~~ $P(Y\geq y|\pi_0)\leq \alpha/2, \] where \(y\) is the observed number of successes. This is equivalent to rejecting \(H_0\) if \[ \min\{2\,P(Y \leq y|\pi_0), 2\,P(Y\geq y|\pi_0)\}\leq \alpha. \] So could define the \(p\)-value as \[ \min\{2\,P(Y\leq y|\pi_0), 2\,P(Y \geq y|\pi_0),1\}. \] Inverting this exact test will give the Clopper-Pearson confidence interval, which will have a coverage probability that is always at least \(1-\alpha\).

    For our example, \(P(Y\leq 4|\pi=1/3)=0.1515\), and \(P(Y\geq 4|\pi=1/3)=0.9396\). Thus, \(y=4\) is in the left tail. Thus, the \(p\)-value is \(2\,P(Y\leq 4|\pi=1/3)=0.3030\). 
    > pbinom(4,size=20,prob=1/3)
[1] 0.1515109
> sum(dbinom(4:20,size=20,prob=1/3))
[1] 0.9395535
  • It can be shown, by exploiting the relationship between the binomial and the beta distributions, that the limits for the the Clopper-Pearson confidence interval can be computed as follows: \[ \mbox{lower limit} = \left\{ \begin{array}{ll} qbeta(\alpha/2; y,n-y+1), & y\neq 0 \\ 0, & y=0 \end{array} \right. \] and \[ \mbox{upper limit} = \left\{ \begin{array}{ll} qbeta(1-\alpha/2; y+1,n-y), & y\neq 0 \\ 1, & y=n\end{array} \right. \] where qbeta is the quantile function for the beta distribution with two shape parameters. We will verify the computation of the limits of the 95% Clopper-Pearson for \(\pi\). The lower limit is \(qbeta(0.025; 4,17)=0.057\) and the upper limit is \(qbeta(0.975; 5,16)= 0.4366\). 
    > qbeta(0.025, 4,17)
[1] 0.057334
> qbeta(0.975, 5,16)
[1] 0.436614


Example 8 : Exact Methods



In this example, we will use the function binom.exact from the exactci package. We start by installing the package. 

> install.packages("exactci")


To use the package in a new session, we use the command: 

> library(exactci)


When using the function binom.exact from the exactci package, we have the argument tsmethod which we can use the specify the \(p\)-value method that we prefer. It can be "central", "minlike", or "blaker". By default, it is the central method that is used, which give the Clopper-Pearson confidence interval. The given confidence interval is the inversion of the corresponding test.

Suppose that we have \(y=6\) successes in a binomial experiment with \(n=21\) trials to test \(H_0:\pi=0.22\) against \(H_a:\pi\neq 0.22\). To get the exact binomial test with the central method, and the corresponding Clopper-Pearson confidence interval. 
> library(exactci)
> binom.exact(x=6,n=21,p=0.22)

        Exact two-sided binomial test (central method)

data:  6 and 21
number of successes = 6, number of trials = 21, p-value = 0.6161
alternative hypothesis: true probability of success is not equal to 0.22
95 percent confidence interval:
 0.1128094 0.5217511
sample estimates:
probability of success
             0.2857143


Comments:
  • The \(p\)-value for the exact binomial test with the central method, we compute \[ \min\{1, 2\,P(Y\leq y|\pi=0.22), 2\,P(Y\geq y|\pi=0.22)\}, \] where \(y\) is the observed number of successes.
  • The Clopper-Pearson confidence interval at \(1-\alpha\) is \(\{\pi_0\in [0,1]~:~ p\mbox{-value}(\pi_0)>\alpha\}\), in other words it is the inversion of the exact binomial test with central method.
  • Let us verify the computation of the \(p\)-value. We start by computing the tail probabilities for \(y=6\): \(P(Y\leq 6|\pi=0.22)=0.8400\) and \(P(Y\geq 6|\pi=0.22)=0.3080\). Since the right-tail probability is the smallest, this means that \(y=6\) is in the right-tail. So the \(p\)-value is \(2\,P(Y\geq 6)=0.6161\). 
    > sum(dbinom(0:6,21,0.22))
[1] 0.8400319
> sum(dbinom(6:21,21,0.22))
[1] 0.3080381
> 2*sum(dbinom(6:21,21,0.22))
[1] 0.6160762

  • The corresponding confidence interval at \(1-\alpha\) is \(\{\pi_0\in [0,1]~:~ p\mbox{-value}(\pi_0)>\alpha\}\), in other words it is the inversion of the exact binomial test with the min likelihood method.
  • Let use verify the computation of the \(p\)-value. We will display the mass for all values in the support of the \(B(n=21,\pi=0.22)\) distribution.

Comments:
  • To compute the \(p\)-value for the exact binomial test with the Blaker method is the combine the smaller observed tail probability with the largest attainable tail probability in the opposite tail that is not greater than the observed tail.
  • The Blaker confidence interval at \(1-\alpha\) is \(\{\pi_0\in [0,1]~:~ p\mbox{-value}(\pi_0)>\alpha\}\), in other words it is the inversion of the exact binomial test with the Blaker method. It can be shown that the Blaker interval will always be contained in the Clopper-Pearson interval.
  • As see above \(y=6\) is in the right-tail. So let us compute a few left-tail probabilities. The largest of these left-tail probabilities that is not greater than \(P(Y\geq 6|\pi=0.22)=0.3080\) is \(P(Y\leq 3|\pi=0.22)=0.2898\). Thus, the \(p\)-value is \[ P(Y\geq 6|\pi=0.22)+P(Y\leq 3|\pi=0.22)=0.3080+0.2898=0.5978. \]

Example 10 : Monte Carlo simulation to estimate the coverage probability (i.e. the true confidence level)



Consider a binomial experiment with $n=50$ and the probability of success is 0.184. We want to estimate the coverage probability (i.e. the true confidence level) of the Wald confidence interval for the probability of success with a level of confidence of 95%. We will use a Monte Carlo simulation to estimate the coverage probability. We generate randomly 5000 values from a $B(n=50,\pi=0.184)$ distribution. For each of these values, we construct a 95% Wald confidence interval for the probability of success. We estimate the coverage probability by computation the sample proportion of these intervals that contain the probability of success of 0.184.

We use the following commands to estimate that the coverage probability is about 90%. 
## initialize parameters
alpha<-0.05
pi<-0.184
n<-50
#################################
# Number of binomial samples of size n

w<-rbinom(n = nSim, size = n, prob = pi)
#################################
# compute Wald CI for each sample
c.int<-binom.confint(x=w,n=n,conf.level=1-alpha,methods="asymptotic")
#################################
# verify that the population parameter is in CI
parameter.in.ci<-ifelse(test = ( pi > c.int$lower ) & ( pi < c.int$upper ), yes = 1, no = 0)
#################################
# compute and display the estimate of the true coverage probability
true.conf<-mean(parameter.in.ci)
cat("An estimate of the coverage probability is:", round(true.conf,4), "\n")

Example 15 : Coverage Probability when estimating a difference of proportions



We will compute the coverage probability for the confidence interval for a difference of proportions using the Wald method, the Agresti-Caffo method, and the Wilson method (i.e. the score CI), respectively. We will fix the probability of success for the group 2 to 0.25. For the probability of success for group 1, we will use various values between 0 and 1. In fact, we will use 0.001 to 0.999 by increments of 0.0005.

Here are the commands that we used to produce the plot that is found below. 
## load the PropCIs package
library(PropCIs)
################################################
## initialize parameters
n1<-10
n2<-10
alpha<-0.05
pi2<-0.45
pi1<-seq(from = 0.001, to = 0.999, by = 0.0005)
length.pi1.seq<-length(pi1)
## intialize a matrix to store results
coverage.prob<-matrix(data = NA, nrow = length.pi1.seq, ncol = 4)
##############################################
# All possible combinations of w1 and w2
w.all<-expand.grid(w1 = 0:n1, w2 = 0:n2)
##############################################
## compute all possible confidence intervals
## by iterating over each row of w.all
ci.wald<-matrix(data = NA, nrow = nrow(w.all), ncol = 2)
ci.ac<-matrix(data = NA, nrow = nrow(w.all), ncol = 2)
ci.wilson<-matrix(data = NA, nrow = nrow(w.all), ncol = 2)
for (i in 1:nrow(w.all))
{
  # Wald
  c.int<-wald2ci(x1 = w.all[i,1], n1 = n1, x2 = w.all[i,2], n2=n2, conf.level = 1-alpha, adjust = "Wald")
  ci.wald[i,]<-c.int$conf.int
  # Agresti-Caffo
  c.int<-wald2ci(x1 = w.all[i,1], n1 = n1, x2 = w.all[i,2], n2=n2, conf.level = 1-alpha, adjust = "AC")
  ci.ac[i,]<-c.int$conf.int
  # (Wilson) Score
  c.int<-diffscoreci(x1 = w.all[i,1], n1 = n1, x2 = w.all[i,2], n2=n2, conf.level = 1-alpha)
  ci.wilson[i,]<-c.int$conf.int
}
##################################################################################
# Iterate over each pi and compute the coverage probability
for(i in 1:length.pi1.seq)
   {
      pmf<-dbinom(x = w.all[,1], size = n1, prob = pi1[i])*dbinom(x = w.all[,2], size = n2, prob = pi2)

      # Wald
      parameter.in.ci<-ifelse(test = (pi1[i]-pi2 > ci.wald[,1])&(pi1[i]-pi2 < ci.wald[,2]), yes = 1, no = 0)
      wald<-sum(parameter.in.ci*pmf)


      # Agresti-Caffo
      parameter.in.ci<-ifelse(test = (pi1[i]-pi2 > ci.ac[,1])&(pi1[i]-pi2 < ci.ac[,2]), yes = 1, no = 0)
      AC<-sum(parameter.in.ci*pmf)

      # (Wilson) Score
      parameter.in.ci<-ifelse(test = (pi1[i]-pi2 > ci.wilson[,1])&(pi1[i]-pi2 < ci.wilson[,2]), yes = 1, no = 0)
      wilson<-sum(parameter.in.ci*pmf)

      coverage.prob[i,]<-c(pi1[i], wald, AC, wilson)

}

# Plot
x11(width = 7, height = 6, pointsize = 12)
## plot coverage probablity for Wald
plot(x = coverage.prob[,1], y = coverage.prob[,2], xlab = expression(pi[1]),
    ylab = "Coverage Probability", type = "l", ylim = c(0.85,1), lty = 1, col = "blue",
    main =expression(paste("Estimation of ",pi[1]-pi[2]," with ", pi[2] == 0.45,",", n[1]==10,",", n[2]==10)))
## add Agresti-Caffo to the plot
lines(x = coverage.prob[,1], y = coverage.prob[,3], lty = 2, col = "red")
## add Score to the plot
lines(x = coverage.prob[,1], y = coverage.prob[,4], lty = 3, col = "forestgreen")
## add a horizontal line at 95%
abline(h = 1-alpha, lty = "dotted")
## add a legend
legend(x = 0.1, y = 0.88, legend = c("Wald", "Agresti-Caffo","Score"), lty = c(1,2,3),
    bty = "n", col = c("blue", "red","forestgreen"))

Models:
  • Saturated Model: To assess the fit of a model, we can compare it to the fit of the saturated model. The saturated model is the model that gives to each unit its own probability of success. The saturated model is \(\pi_i=E[Y_i]\), for \(i=1,2,\ldots,n\). (If we have binomial outcomes, it is \(\pi_i=E[W_i/n_i]\), for \(i=1,2,\ldots,n\). )

    There are \(n\) free parameters to estimate. So we say that the saturated model has \(n\) degrees of freedom. The mle for \(\pi_i\) is \(y_i\), which is the observed binary outcome. (If we have binomial outcomes, the mle for \(\pi_i\) is \(w_i/n_i\), which is the observed sample proportion for that unit.)

  • Our Model: Our logistic model is \[ \pi_i=\frac{\exp(\beta_0+\beta_1\,x_1+\beta_2\,x_2+\beta_3\,x_3)}{1+\exp(\beta_0+\beta_1\,x_1+\beta_2\,x_2+\beta_3\,x_3)}, \] for \(i=1,2,\ldots,n\). It has 4 free parameters, so we say that it has 4 degrees of freedom.

    Residual: To describe the fit of our model, we compute the deviance between our model and the saturated model. This deviance is called the residual deviance. It is \[ \mbox{Res Dev}=-2\sum_{i=1}^n y_i\,\log(\frac{\hat{\pi}_i}{y_i})+(1-y_i)\,\log(\frac{1-\hat{\pi}_i}{1-y_i}), \] where \(\hat{\pi}_i\) is the estimated probability of success for the $i$th unit. If we have a binomial outcome, it is \[ \mbox{Res Dev}=-2\sum_{i=1}^n w_i\,\log(\frac{\hat{\pi}_i}{w_i/n})+(n_i-w_i)\,\log(\frac{1-\hat{\pi}_i}{1-w_i/n_i}) \] The degrees of freedom for the residual deviance is \(n-(\mbox{degrees of freedom of our model})\). So it is \(n-4=159-4=155\) in our example.

    In this example, the residual deviance is 105.1. A smaller residual deviance is interpreted as a better fit.
  • Null Model: The null model is the logistic regression model with just the intercept. It is \[ \pi_i=\frac{\exp(\beta_0)}{1+\exp(\beta_0)}, \] for \(i=1,2,\ldots,n\). It has 1 free parameter, so we say that it has 1 degree of freedom.

    The null deviance is computing the deviance between the null model and the saturated model. Here it is 134.9. Its degrees of freedom is \(n-1=158).


Test for the significance of the regression: This is an omnibus test to identify if any of the predictors are significant. \[ H_0: \mbox{logit}(\pi)=\beta_0 ~~ \mbox{ versus } ~~ H_1: \mbox{logit}(\pi)=\beta_0+\beta_1\,x_1+\beta_2\,x_2+\beta_3\,x_3. \] We have two models that we would like to compare: (i) a reduced model under \(H_0\), (ii) the full model under \(H_1\). To compare the models, we can compare their residual deviance. In this case, it is the residual deviance of the null model, which is called the null deviance, and the residual deviance of the full model. The difference between the null deviance and the residual deviance of our model is the deviance between the two models. The number of degrees of freedom for this deviance is the difference between the degrees of freedom for the residual deviance under \(H_0\) and the number of degrees of freedom for the residual deviance under \(H_1\). In our case, it is \(\mbox{df}=158-155=3\). 
> ## residual deviance
> mod$deviance
[1] 105.0932
> ## null deviance
> mod$null.deviance
[1] 134.9408
> ## deviance between the two models
> mod$null.deviance-mod$deviance
[1] 29.84759
> ## df for the deviance between these two models
> mod$df.null-mod$df.residual
[1] 3
> 1-pchisq(mod$null.deviance-mod$deviance,mod$df.null-mod$df.residual)
[1] 1.485781e-06
The \(p\)-value is \(p\)-value \(=P(\chi^2(3) > 29.84759) < 0.0001\). We have significant evidence that our logistic regression model is significant.

Example 20a : Describing the fit of a binomial regression model



When fitting a linear there are a few descriptive measures of fit: $R^2$, $\sqrt{\mbox{MSE}}=\hat{\sigma}$. These measures are a description of the error on some numeric scale (i.e. relative or absolute). However, with a binomial model the response for a statistical unit (i.e. a Bernoulli trial) is either 1 (success) or 0 (failure). So to describe the fit in this case, we can describe how well the model is classifying the observations. So the description is done at a classification point of view.

Probabilistic Classification: Consider the $i$th Bernoulli trial. We estimate the probability of success and failure given the value of the predictor, and we classify the unit as being a success if $P(\mbox{success})>P(\mbox{failure})$, else it is classified as a failure.

    Broken line regression with a known breaking point:

    We will use a broken line regression model (also called a segmented line regression model, or a linear spline model). Consider the following logit model \[ \mbox{logit}(\pi)=\beta_0+\beta_1\,x+\beta_2\,\delta_b\,(x-b)=\left\{ \begin{array}{ll} \beta_0+\beta_1\,x, & \mbox{ if } x< b \\ \beta_0+\beta_1\,x+\beta_2\,(x-b)=(\beta_0-b\,\beta_2)+(\beta_1+\beta_2)\,x, & \mbox{ if } x \geq b \\ \end{array} \right. \] where \(\delta_b\) is dummy variable that is 1 for \(x\geq b\) and is 0 for \(x < b \).

    \(b\) is called a breakpoint or a knot. Note that we are assuming the link is a continuous function with two linear segments. (It is a continuous function since the two linear functions are equal at the boundary, that is \(\mbox{logit}(\pi)=\beta_0+\beta_1\,b\) at \(x=b\).)

    \(h(x)=\delta_b\,(x-b)\) is called a hinge function. It is a predictor that we add to the model (asuming that \(b\) is known).

    If we assume that \(b\) is unknown, then our model is non-linear in the parameters \((\beta_0,\beta_1,\beta_2,b)\). However, if we assume that the breakpoint \(b\) is known, then our model is simply a logistic regression model for which we can compute the max log likelihood. As an example, let us suppose that the breakpoint is \(b=17\) log(dollars) or we say we have a knot at \(b=17\) log(dollars). The model is : \[ \mbox{logit}(\pi)=\beta_0+\beta_1\,x+\beta_2\,h(x)=\left\{ \begin{array}{ll} \beta_0+\beta_1\,x, & \mbox{ if } x< 17 \\ \beta_0+\beta_1\,x+\beta_2\,(x-17)=(\beta_0-17\,\beta_2)+(\beta_1+\beta_2)\,x, & \mbox{ if } x \geq 17 \\ \end{array} \right. \] There is a package called lspine that builds the hinge function for us, and displays the coefficients in a convenient way.     Example 23 : A few links: Logit, Probit, Complementary log-log, log-log



    Latent Variable Formulation: Suppose that success \(\{Y=1\}\) can be defined in terms of a quantile of some underlying latent continuous variable \(X\). That is, \[ \{Y=1\}=\{X\leq q\}, \] for some \(q\). So \(\pi=P(Y=1)=F_X(q)\). Let us assume that \(X\) has distribution belongs to a location-scale family, i.e. its pdf is of the form \[ f(x|\mu,\sigma)=(1/\sigma)f((x-\mu)/\sigma). \] Here \(f\) is some function such that \(\int_{-\infty}^{\infty} f(x)\,dx=1\). It is the pdf for the standard distribution in this family with location \(\mu=0\) and scale \(\sigma=1\). The corresponding cdf is \[ F(x)=\int_{-\infty}^x f(t)\,dt. \]

    Why use a location scale family? The latent variable is usually not measurable, and so we cannot estimate its distribution. In other words, we cannot estimate \(\mu\) and \(\sigma\). But, we can express the probability of success in terms of a quantile of the standard distribution in the family, since by taking \(q'=(q-\mu)/\sigma\), we have \[ \pi=P(Y=1)=P(X\leq q)=P\left( \frac{X-\mu}{\sigma}\leq \frac{q-\mu}{\sigma} \right)=F(q'). \]

    Underlying regression model for the latent variable: We will try to estimate the quantile \(q'\) for the underlying latent variable that leads to success as a function of the predictors \(x_1,x_2,\ldots,x_p\). Let us consider the model: \[ q'=\beta_0+\beta_1\,x_1+\cdots+\beta_p\,x_p. \] Thus, we get the model: \[ \pi=P(Y=1)=F(q')=F(\beta_0+\beta_1\,x_1+\cdots+\beta_p\,x_p), \] or equivalently \[ F^{-1}(\pi)=\beta_0+\beta_1\,x_1+\cdots+\beta_p\,x_p. \]

    Logistic latent variable and the logistic model: If we assume that the latent variable has a logistic distribution, its pdf is \[ f(x|\mu,\sigma)=(1/\sigma)\,f((x-\mu)/\sigma), ~~ \mbox{where } ~~ f(x)=\frac{e^{-x}}{(1-e^{-x})^2}. \] The cdf for the standard logistic is \[ F(x)=\frac{e^{x}}{1+e^x}. \] This gives us the following model \[ \beta_0+\beta_1\,x_1+\cdots+\beta_p\,x_p=F^{-1}(\pi)=\mbox{logit}(\pi), \] which is the logistic regression model.

    Normal latent variable and the probit model: In the social sciences, they often assume that the underlying latent variable has a normal distribution (this assumption cannot be verified). The pdf of the latent variable is \[ f(x|\mu,\sigma)=(1/\sigma)\,f((x-\mu)/\sigma), ~~ \mbox{where } ~~ f(x)=\frac{1}{\sqrt{2\,\pi}}\,e^{(x-\mu)^2/(2\,\sigma^2)}. \] The cdf for the standard logistic is \[ \Phi(x)=\int_{-\infty}^x \frac{1}{\sqrt{2\,\pi}}\,e^{(z-\mu)^2/(2\,\sigma^2)}\,dz. \] The corresponding quantile function \(\Phi^{-1}\) is called the probit function by statisticians, and is the link function for the following generalized linear model: This gives us the following model \[ \beta_0+\beta_1\,x_1+\cdots+\beta_p\,x_p=\Phi^{-1}(\pi), \] which is called the probit regression model.

    The response function for the probit regression model is \(\pi=E[Y]=\Phi(\beta_0+\beta_1\,x_1+\cdots+\beta_p\,x_p)\).

    Likelihood ratio test for testing the independence between the $X$ and $Y$: The null hypothesis for independence is $H_0:\pi_{ij}=\pi_{i+}\pi_{+j}$ for $i=1,2,\ldots,I$; $j=1,2,\ldots,J$. Let us reexpress these equations in terms of the conditional distribution of $Y$ according to the level of $X$. We have $\pi_{j|i}=P(Y=j|X=i)=P(Y=j,X=i)/P(X=i)=\pi_{ij}/\pi_{i+}$. Thus, the equation for cell $(i,j)$ in $H_0$ can be reexpressed by dividing by $\pi_{i+}$. We get $$ H_0:\pi_{j|i}=\pi_{+j}$ ~~~ \mbox{for $i=1,2,\ldots,I$; $j=1,2,\ldots,J$}. $$ In other words, we are testing for the homogeneity of the conditional distributions of the response.

    Let us consider three log linear models (i.e. Poisson regression models with categorical explanatory variables). Here our goal is to study the associations between these three categorical variables: alcohol, smoke, marijuana. In our notation below, we will use \(X\)=alcohol, \(Z\)=smoke, \(W\)=marijuana.

    The mutual independence model is \[ \log(\mu_{ijk})=\beta_0+\beta_{i}^X+\beta_{j}^Z+\beta_k^W, ~~~ i=0, 1; j=0, 1; k=0, 1. \]

    Remarks:
    • Recall that \(\beta_{i}^X\), \(\beta_{j}^Z\), and \(\beta_k^W\) are effects that describes deviations away from the baseline.
    • The reference (i.e. baseline) category for all three variables is the level=0. So \(\beta_{0}^X=\beta_{0}^Z=\beta_0^W=0\), since a deviation away from itself is zero.
    • So our model only has 4 free parameters~:~ \(\beta_0\), \(\beta_{1}^X\), \(\beta_{1}^Z\), \(\beta_1^W\).
    • Interpreting the parameters: Let \(Z\), and \(W\) remain fix, and let switch from \(X=0\) to \(X=1\), we get \[ \frac{\pi_{1jk}}{\pi_{0jk}}=\frac{\mu_{1jk}}{\mu_{0jk}}= \exp\left( \beta_1^X \right). \] So \(e^{\beta_1^X}\) is the odds that a student consumed alcohol. Since an odds is \(\pi/(1-\pi)\), we can easily into a probability: \(\pi=\mbox{odds}/(1+\mbox{odds})=e^{\beta_1^X}/(1+e^{\beta_1^X})\).

      Example 35 : A few diagnostic tools



      In this example, we discuss a few diagnostic tools. The most general tool for a generalized linear model is the half-normal plot of the deviance residuals.

      Deviance Residuals: We can consider the residual deviance for a model as a sum of squares, i.e. Res. Deviance \(=\sum_{i=1}^n r_i^2\). The value $r_i$ is the deviance residual. (We usually attribute a sign to the residual as follows: \(\mbox{sign}(y_i-\hat{ \mu}_i\).)

      Half-normal plot and Residual plot: A half-normal plot of the deviance residuals with a simulated envelop is useful for examining the adequacy of the model of the binomial model. It can also be used to identify outlying values, and overdispersion. A plot of the residuals against the fitted values (i.e. the estimated probabilities for a binomial regression model) with an overlay of a loess smooth curve can be useful to identify inadequacies of the model. It can be useful to identify a miss specification of the model.

      Coupon Data: Let us consider the coupon data from Example 20a. We use the hnp package, to build the half-normal plot for the fitted logistic model. The points are well within the simulated envelopes. Furthermore, there are little to no tendencies in the residual plot. These plots suggests that the binomial regression model with a logit link with the current linear predictor is appropriate.

      Ramsey's RESET: RESET is regression specification error test. It is an approximate test. To identify non-linear effects, we could include higher order terms. However, this would increase the number of parameters to estimate, which would make the model more variable. In 1969, Ramsey suggested to fit the model (for linear models), and to include the square and the cube of the fitted values in the model. This would only increase the number of degrees of freedom by 2. The RESET test is to test for the significance of these added terms which are higher order functions of the predictors. If they are significant, then we have evidence that there are non-linear effects, and the model is miss specified. These ideas also work for a generalized linear model. But instead of using the fitted values which are at the level of the response, we should use the estimated link.

      Reference: Ramsey, J. B. (1969). "Tests for Specification Errors in Classical Linear Least Squares Regression Analysis". Journal of the Royal Statistical Society, Series B. 31 (2): 350–371.

      To implement, we Ramsey's RESET, we fit the logistic model, we obtained the estimated link for each observation. We added the square and the cube of the link to the model. We compared the full model with the added higher order effects to our model with a likelihood ratio test. According to Ramsey's RESET, there is significant evidence that the model is miss specified (\(X^2(2)=45.399, p<.0001\)).

      Overdispersion: With a binomial regression model, we are assuming that all observations with the same values of the predictors are a result of a binomial experiment with the same probability of success \(\pi(x)\). However, if we missing important predictors, then this probability of success might not be fixed. This will often manifest itself as overdispersion, i.e. the variance is larger than expected. This is also true, for a Poisson regression model. We are assuming that the count with the same values for the predictors, are Poisson random variables with the same rate (i.e. mean) parameter. But, if we are missing important predictors, then these observations might not have the same rate, causing overdispersion.

      We can often identify overdispersion with the half-normal plot of the deviance residuals. Another, it to estimate an overdispersion parameter. Let us introduce an overdispersion scaling parameter \(\phi\) such that \(E[Y_i|x_i]=\mu_i\), but \(V[Y_i|x_i]=\phi^2\,\sigma_i^2\), where $\sigma_i^2$ is the variance of Y|x for the given model from the exponential family of interest.

      We coerce extract to be a factor, and fit the logistic regression model. 
      > corn$extract<-factor(corn$extract)
> model<-glm(y/m~extract,weights=m,family=binomial("logit"),data=corn)
      The half-normal plot of the deviance residuals is suggesting that binomial regression model with a logit link is not appropriate. When all the predictors are categorical, the mean response function cannot be miss specified. This suggests that the inadequacy of the model might be caused by overdispersion.

      The Binomial-logit-normal model: If the beta-binomial is not sufficient to account for the overdispersion, an alternative model is to use a normal-binomial model. That is, we add some random noise to the intercept. In other words, we are using a random intercept.

      To fit the model, we need a factor to identify each of the observations. 
      > x <- factor(seq_len(nrow(corn)))

      > library("lme4")
> fit4_b <- glmer(cbind(y, m - y) ~ extract + (1 | x),
